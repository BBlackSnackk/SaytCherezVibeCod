# Вівальді — інтернет-магазин одягу чотирьох сезонів

Навчальний проєкт: односторінковий інтернет-магазин одягу для всієї родини, натхненний «Порами року» Антоніо Вівальді, з власною CRM. Магазин, товари й контакти вигадані: замовлення потрапляють у CRM, але оплати й доставки немає.

## Можливості

- **Одна сторінка-«стрічка»** з меню для швидкого переходу між розділами: сезони, розміри, доставка, про нас, відгуки, контакти.
- **Колір сайту змінюється за сезоном** під час прокручування: весна — салатовий, літо — насичений зелений, осінь — помаранчевий, зима — синій.
- **Каталог із 36 товарів**: 4 сезони × жінки / чоловіки / діти × 3 моделі. У кожного товару є ціна, знижка, рейтинг, кольори, розміри, склад, наявність і два фото.
- **Фільтри**: для кого, сезон, категорія, ціна, розмір, колір, «лише в наявності», сортування, пошук.
- **Картка товару**: вибір кольору й розміру, перемикання фото «на моделі / всі кольори».
- **Кошик** зберігається в браузері (localStorage) і показує, скільки лишилося до безкоштовної доставки.
- **Віва-бот**: оформлення замовлення в чаті (ім'я, перевірка телефону, місто, Нова Пошта / Укрпошта / кур'єр, оплата), підбір розміру, відповіді на часті запитання.
- **Три мови**: українська (основна), російська й англійська. Перемикач у шапці; вибір запам'ятовується, а посилання з `?lang=ru` чи `?lang=en` відкриває сайт потрібною мовою. Пошук розуміє всі три мови.
- **Адаптивна верстка**: телефон, планшет, ноутбук, великий монітор.

## Технології

Чистий HTML, CSS і JavaScript без фреймворків і збирання. Шрифти Prata та Manrope з Google Fonts. Фото товарів і банери згенеровано в Google Gemini.

## Структура

```
index.html          сторінка магазину
404.html            сторінка «не знайдено»
css/style.css       стилі й теми сезонів
js/data.js          каталог: сезони, категорії, кольори, товари
js/products-i18n.js переклади товарів (запасні, якщо в базі їх немає)
js/i18n.js          мови сайту: словник, перемикач, переклад довідників
js/app.js           каталог, фільтри, картка товару, кошик, зміна теми
js/bot.js           Віва-бот
images/             логотип, банери сезонів
images/products/    фото товарів: <код>-1.jpg (на моделі), <код>-2.jpg (всі кольори)
PROMPTS-GEMINI.md   аналіз ринку та промпти для генерації фото
tools/              скрипт генерації фото через Gemini API
```

## Як запустити локально

Відкрийте `index.html` у браузері — сервер не потрібен.

## Оновлення сайту й кеш браузера

У `index.html` і `admin.html` до стилів і скриптів додано версію, напр. `js/app.js?v=20261119c`. Після змін у CSS чи JS змініть версію в обох файлах — тоді браузери відвідувачів завантажать свіжі файли, а не старі з кешу.

## Мови сайту

- Українська — основна: сайт завжди відкривається нею, якщо відвідувач сам не обрав іншу мову.
- Статичний текст сторінки позначено атрибутом `data-i18n="ключ"`; українська береться прямо з `index.html`, а російський та англійський переклади — зі словника `STATIC` у `js/i18n.js`.
- Рядки, які будує JavaScript (каталог, кошик, бот), — функція `t('ключ')` і словник `DICT`.
- Переклади товарів зберігаються в базі (`products.i18n`) і редагуються в CRM у блоці «Переклади для сайту». Незаповнене поле показується українською.
- Замовлення в CRM завжди українською (спосіб доставки, адреса), а мова, якою клієнт оформив замовлення, видна в картці замовлення й у сповіщенні в Telegram.

## Як додати або змінити товар

1. Додайте об'єкт у масив `PRODUCTS` у `js/data.js` з новим кодом, наприклад `wi-k-4`.
2. Покладіть фото в `images/products/`: `wi-k-4-1.jpg` (на моделі, перший колір) і `wi-k-4-2.jpg` (усі кольори). Рекомендований розмір — 900×1200 px, JPEG.
3. Поки фото немає, сайт показує кольорову заглушку з емодзі.

## CRM (Supabase)

Адмінка магазину — `admin.html`, дані — у базі [Supabase](https://supabase.com) (PostgreSQL).

- **Замовлення**: статуси (Новий → Підтверджений → Відправлений → Отриманий / Повернення / Скасований), ТТН Нової Пошти з посиланням на відстеження, нотатки менеджера.
- **Клієнти**: картка з історією замовлень, сумою покупок і нотатками.
- **Товари й залишки** (лише адміністратор): назва, ціна, знижка, опис, переклади RU/EN, видимість на сайті, залишок для кожного розміру й кольору.
- **Статистика** (лише адміністратор): виручка, середній чек, графік по днях, популярні товари, «мало на складі».
- **Сповіщення в Telegram** про кожне нове замовлення.

Як це влаштовано:

- `supabase/schema.sql` — таблиці, правила доступу (Row Level Security) і функції. Відвідувач сайту бачить лише каталог і може лише оформити замовлення; замовлення, клієнти й склад доступні тільки співробітникам.
- `place_order` — оформлення замовлення на сервері: ціни беруться з бази (підробити суму в браузері неможливо), залишок списується атомарно, захист від спаму — не більше 5 замовлень з одного номера на годину.
- Скасування чи повернення автоматично повертає товар на склад.
- `supabase/functions/notify-order` — Edge Function, що надсилає сповіщення в Telegram. Токен бота зберігається в Supabase Vault (зашифровано), у коді його немає; кожне замовлення сповіщається рівно один раз.
- `js/config.js` — адреса бази й **публічний** ключ (роль anon). Секретний ключ `service_role` у коді ніколи не зберігається.

## Що можна покращити далі

- Підказки міст і відділень через API Нової Пошти.
- Онлайн-оплата (Monobank, WayForPay, LiqPay).
- Окремі сторінки товарів для пошукових систем.
